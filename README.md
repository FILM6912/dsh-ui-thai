# DSH UI Thai

ปลั๊กอินภาษาไทยสำหรับ **DeepSeek Harness 0.2.2-rc.3** เพิ่ม **ไทย** ในตัวเลือกภาษาของแอปผ่านระบบ locale เดิม ไม่แก้แอปหลัก ไม่แทนข้อความใน DOM และไม่ส่งข้อมูลออกเครือข่าย

**3,491 คีย์ ใน 67 หมวดภาษา** ตามชุดต้นฉบับที่ตรวจสอบไว้ ไม่ใช่การรับรองว่าทุกส่วนของแอปและปลั๊กอินภายนอกเป็นภาษาไทยแล้ว

## วิธีติดตั้ง

### 1. ดาวน์โหลดปลั๊กอิน

ใช้ Git ใน Terminal หรือ PowerShell

```sh
git clone https://github.com/FILM6912/dsh-ui-thai.git
```

หรือกด **Code → Download ZIP** บน GitHub แล้วแตก ZIP ก่อนติดตั้ง

ไม่ต้องรัน `npm install` หรือ build เพื่อใช้งาน มี [client.js](<client.js>) ที่สร้างไว้แล้วและไม่มี runtime dependency เพิ่มเติม

### 2. ติดตั้งใน DeepSeek Harness

1. เปิด **Plugins → Add plugin**
2. เลือกติดตั้งจากไดเรกทอรีในเครื่อง
3. เลือกโฟลเดอร์ที่ clone หรือแตก ZIP ซึ่งมี [package.json](<package.json>) อยู่โดยตรง ไม่เลือกโฟลเดอร์แม่
4. ตรวจว่าปลั๊กอิน **Thai language pack / ชุดภาษาไทย** เปิดใช้งานแล้ว

หากต้องการให้เอเจนต์ติดตั้ง ให้ใช้โหมดที่มีเครื่องมือจัดการปลั๊กอิน แล้วส่งคำขอนี้โดยแทนที่พาธให้ตรงกับเครื่องของคุณ

```text
ติดตั้งและเปิดใช้บันเดิล DSH จากโฟลเดอร์ <พาธเต็มของโฟลเดอร์ dsh-ui-thai> ด้วย plugin_manager แล้วรายงานผลการติดตั้ง
```

ชื่อบันเดิลภายในคือ `@local/dsh-thai` แม้ repository จะชื่อ `dsh-ui-thai` ชื่อนี้ไม่ใช่แพ็กเกจที่เผยแพร่บน npm จึงไม่ใช้ `npm install @local/dsh-thai`

### 3. เลือกภาษาไทย

เปิด **Settings → General → Language → ไทย**

หากยังไม่เห็นตัวเลือก ให้รีเฟรชหน้า หากระบบแจ้งว่าต้องเริ่มใหม่ ให้เริ่ม DeepSeek Harness ใหม่ตามข้อความนั้น ปลั๊กอินไม่บังคับเปลี่ยนภาษาที่คุณเลือกไว้

> รองรับเฉพาะ DSH **0.2.2-rc.3** ตาม `engines.dsh` หากเวอร์ชันไม่ตรง ตัวจัดการปลั๊กอินอาจปฏิเสธการติดตั้ง ไม่ควรข้ามการตรวจเวอร์ชันโดยไม่ได้ทดสอบความเข้ากันได้

## อัปเดตและถอนการติดตั้ง

หากติดตั้งจาก Git ให้รันในโฟลเดอร์ปลั๊กอิน

```sh
git pull --ff-only
```

จากนั้นติดตั้งจากโฟลเดอร์เดิมผ่านตัวจัดการปลั๊กอินอีกครั้ง และทำตามผลลัพธ์เรื่องการเริ่มแอปใหม่ การแก้ไฟล์อย่างเดียวไม่รับประกันว่าหน้าเดิมจะโหลดโค้ดใหม่แล้ว อย่าลบหรือย้ายโฟลเดอร์ที่ติดตั้งไว้ เพราะการติดตั้งจากไดเรกทอรีอาจเชื่อมโยงกับโฟลเดอร์นี้

ถอนการติดตั้งได้ใน **Plugins** โดยเลือกชุดภาษาไทยแล้วปิดใช้งานหรือถอนการติดตั้ง เมื่อปลั๊กอินถูกถอน ภาษาไทยจะถูกนำออกจากรายการและ DSH จะใช้ภาษาสำรองที่พร้อมใช้งาน

### ส่วนที่ยังไม่เป็นภาษาไทยทั้งหมด

- **Annotation 1.4.11** ใช้พจนานุกรมส่วนตัวและเลือกอังกฤษเมื่อภาษาของแอปเป็นไทย
- **dsh-mutipleagent 0.4.1** มีข้อความจีนในตัวครอบและหน้า iframe ที่เลือกภาษาแยกเอง
- **Plugin Hub 2.3.9+sidebar.1** ใช้พจนานุกรมส่วนตัวในหน้าหลักและเลือกจีนเมื่อภาษาไม่ใช่อังกฤษ ปุ่มสลับภาษาของปลั๊กอินนี้ยังเปลี่ยนภาษาของทั้งแอปได้
- **Codex Connect** ส่วนกู้คืนงานมีข้อความอีก 12 คีย์ในพจนานุกรมอังกฤษ/จีนส่วนตัว ซึ่งไม่รับคำแปลจากแพ็กนี้
- ข้อมูลเมตา คำอธิบายและเอกสารของปลั๊กอินอื่น รวมถึงข้อความฝังตาย ข้อผิดพลาดจากเซิร์ฟเวอร์ เว็บไซต์ และข้อความที่สร้างขึ้น อาจยังเป็นภาษาอื่น
- ตัวเลือกภาพ onboarding และภาษาภายในตัวแสดงสเปรดชีตคงเป็น `en` เนื่องจากยังไม่ได้ยืนยันว่ามีทรัพยากรภาษาไทยสำหรับตัวแสดงเหล่านั้น
- ชื่อผลิตภัณฑ์ โมเดล URL รหัส API และคำสั่งคงเดิมตามหน้าที่ ข้อความสนทนาและโค้ดของผู้ใช้ไม่ถูกแปล

English fallback มีไว้รองรับคีย์ใหม่หรือคีย์ที่ไม่มีคำแปล ไม่ถือว่าเป็นการแปลครบ การแก้ส่วนที่ใช้ระบบภาษาแยกต้องแก้ปลั๊กอินเจ้าของ ไม่ใช่เพิ่มคีย์ในแพ็กนี้อย่างเดียว

## พัฒนาและทดสอบ

ใช้ Node.js 24 ขึ้นไป ไม่ต้องติดตั้ง dependency สำหรับ build และ unit tests

```sh
node tools/build.mjs
node tools/build.mjs --check
node --test tests/pack.test.mjs
node --check client.js
```

- [translations](<translations/>) เป็นคำแปลไทยแยกตามหมวด
- [sources/en.json](<sources/en.json>) เป็นต้นฉบับภาษาอังกฤษ 58 หมวดแรก
- [sources/previews-en.json](<sources/previews-en.json>) เก็บอีก 8 หมวดพร้อมหลักฐานต้นฉบับแบบพาธภายในแพ็กเกจ
- [sources/codex-en.json](<sources/codex-en.json>) เก็บต้นฉบับส่วน Codex ที่ใช้ในแพ็กนี้
- [tools/build.mjs](<tools/build.mjs>) ตรวจคีย์และตัวแปรซ้ำ/ตกหล่น แล้วสร้างไฟล์ client แบบเรียงลำดับแน่นอน
- [tests/pack.test.mjs](<tests/pack.test.mjs>) ตรวจการลงทะเบียน ถอนทรัพยากร เปิดซ้ำ และย้อนกลับเมื่อการลงทะเบียนล้มเหลว

### การทดสอบกับ DSH ที่ติดตั้งจริง

รันจาก PowerShell ของ DSH Desktop ซึ่งมี `DSH_NODE_EXECUTABLE` และ `DSH_INSTALL_DIR`

```powershell
./tools/electron.ps1 tools/test-real-locale.cjs
```

การทดสอบนี้ใช้ LocaleRuntime จาก DSH ที่ติดตั้งจริง ตรวจข้อความและการแทนตัวแปรครบ 3,491 คีย์ โดยแทนเฉพาะ UI imports ที่ไม่ได้ใช้ด้วย stub ไม่ใช่การทดสอบเบราว์เซอร์

ผลที่ตรวจแล้วก่อนเผยแพร่คือ unit tests 6 รายการ การสร้างซ้ำ การตรวจ syntax และการทดสอบ LocaleRuntime ข้างต้น รวมถึงการติดตั้งในโปรไฟล์ Desktop ซึ่งระบบรายงาน `application: applied` โดยไม่มีคำเตือน ยังไม่ได้ยืนยันการแสดงผลทุกหน้า การตัดบรรทัด ไอคอน หรือการคงค่าภาษาหลังรีเฟรชและเริ่มแอปใหม่ด้วยการควบคุม GUI
